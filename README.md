# Mirror Keep Phone

Mirror Keep（Windows / macOS のPCアプリ）で作った「保存版」を、iPhoneの中に取り込んで、検証・保管・選択し、必要なら動かすための小さなWebアプリです。

## Mirror Keep との関係
- **PC版 Mirror Keep** が、元アプリを完全コピーして保存版を作ります（更新のたびに1つ）。
- PC版の「選択版を書き出し…」で、保存版を **1つのファイル**（`〜.mkbundle.json`）にします。
- そのファイルを、AirDrop・ファイルアプリ・外付けストレージなどで iPhone に移し、この **Mirror Keep Phone** で取り込みます。通信用のサーバーは使いません。
- 両者は同じ形式（`mirror-keep-bundle-v1`）と同じ検証手順（SHA-256）で、互いのファイルを読み書きできます。iPhoneから書き出して、PCで検証することもできます。
- iPhone版は、PC版の代わりではありません。PCのバックアップ・復元・差分更新は、PC版だけの機能です。

## できること
取り込み（複数ファイルを一度に選べる。検証してから保存）／一覧／検証／使用版の選択／削除（確認つき）／書き出し／取り込んだ版を、本物のデータと分離して動かす。

## 守っていること
- 検証に失敗した版は、取り込みも、動かしもしません。
- 保存版は自動では削除しません。保存領域が足りないときは、削除候補を示すだけです。
- 動かすときは、版ごとにデータ（localStorage / sessionStorage / IndexedDB / Cache）を分け、分離できないときは起動しません。
- 分離は、操作ミスで本物のデータを上書きしないためのものです。悪意のある保存版を防ぐ仕組みではないため、自分で書き出したものだけ取り込んでください。

## 制限
- 取り込める1ファイルは300MBまで（PC版の書き出しは200MBまで）。
- iPhoneのブラウザー保存領域は、容量不足のとき端末側に消されることがあります。大事な版は、PCにも残してください。
- ホーム画面に追加したアプリと、Safariで開いたものは、保存領域が別です。同じ方で使ってください。
